# docs/archive/

Documents qui ont eu leur utilité et qu'on ne maintient plus.

Ils sont conservés parce que leur **forme** ou leur **raisonnement** peut servir,
jamais pour leurs valeurs, qui sont périmées par construction. Chacun porte en
tête un avertissement disant à quelle version du dossier il correspond et
pourquoi il a été archivé.

Règle : un document arrive ici quand le maintenir coûterait plus que le refaire.
Il n'en ressort pas, on le réécrit.
